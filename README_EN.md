# DwgSearch

DwgSearch searches and replaces text in DWG files without opening AutoCAD. It is useful for checking or updating repeated labels across many drawings.

## Basic use

1. Install the release according to the project instructions.
2. Select a folder or a group of DWG files.
3. Enter the text to search for.
4. Preview the matches, then enter the replacement text if needed.
5. Review the results and keep backups before batch replacement.

The exact command-line or interface options may vary by release; see the Chinese guide and release notes for details.
